# 01. Game Design Spec

## 1. 게임 콘셉트

중앙 거점 방어형 3인칭 웨이브 슈터.

플레이어는 맵 중앙에서 시작하며, 라운드가 진행될수록 적의 접근 방향이 늘어난다.  
초반에는 북/남 두 방향만 방어하면 되지만, 후반에는 동서남북과 대각선까지 열려 360도 대응이 필요하다.  
5라운드에서는 중앙에 보스가 출현하여 기존 웨이브와 다른 전투 패턴을 제공한다.

## 2. 핵심 플레이 루프

```text
라운드 시작
→ 적 스폰 방향 활성화
→ 적이 중앙으로 접근
→ 플레이어가 엄폐물과 보급을 활용해 처치
→ 모든 적 처치
→ 보상/정비 시간
→ 다음 라운드 시작
```

## 3. 플레이어 목표

- 중앙 거점 생존
- 라운드별 적 처치
- 체력과 탄약 관리
- 5라운드 보스 처치

## 4. 주요 시스템

| 시스템 | 설명 |
|---|---|
| Player System | 3인칭 이동, 조준, 사격, 회피 |
| Weapon System | 탄약, 재장전, 발사, 데미지 |
| Health System | 플레이어/적/보스 체력 |
| Wave System | 라운드별 적 스폰 제어 |
| Spawn System | 방향별 스폰 포인트 관리 |
| Enemy AI | 플레이어 추적, 공격, 사망 |
| Boss AI | 중앙 출현, 패턴 공격 |
| UI System | 체력, 탄약, 라운드, 남은 적 표시 |
| Pickup System | 보급 상자, 회복 아이템 |

## 5. 승패 조건

### 승리 조건

- 5라운드 보스 처치

### 패배 조건

- 플레이어 체력 0
- 선택 사항: 중앙 거점 내구도 0

## 6. 포트폴리오에서 강조할 부분

- 라운드별 스폰 방향 확장 구조
- DataTable 기반 웨이브 밸런싱
- C++ 컴포넌트 기반 설계
- AIController / Behavior Tree 확장 가능성
- Blueprint와 C++의 적절한 역할 분리
