# 02. Map And Wave Metrics

## 1. 기준 설계

첨부 설계도 `중앙 거점 웨이브 슈터 맵 설계도`의 전투 의도를 유지하되, 실제 플레이 밸런스는 정사각형 3인칭 아레나를 기준으로 한다. 동/서/남/북 스폰 거리를 균등하게 맞춰 8방향 웨이브 대응이 한쪽으로 치우치지 않게 한다.

Unreal Engine 기준 1 Unreal Unit = 1 cm로 가정한다.

| 항목 | 값 |
|---|---:|
| 전체 맵 크기 | 4000 x 4000 uu |
| 실제 감각 크기 | 40m x 40m |
| 맵 중심 | `(0, 0, 0)` |
| 중앙 안전/시작 구역 반경 | 300 uu |
| 중앙 전투 링 반경 | 700~850 uu |
| 중앙 순환 이동 링 폭 | 250~350 uu |
| 외곽 스폰 거리 | 중심 기준 1800~2000 uu |
| 대각선 스폰 위치 | X=±1350, Y=±1350 uu |
| 엄폐물 높이 | 120~180 uu |
| 플레이어 키 기준 | 약 180 uu |
| 주요 통로 폭 | 450~700 uu |
| 대각선 진입 통로 폭 | 400~600 uu |

## 3. 좌표계 기준

맵 중심을 `(0, 0, 0)`으로 둔다. X+는 동쪽, X-는 서쪽, Y+는 북쪽, Y-는 남쪽이다. 아래 좌표는 설계도 비율을 반영한 블록아웃 기준값이며, 실제 배치 시 벽/게이트 두께에 따라 약 100 uu 안에서 조정할 수 있다.

| 방향 | 좌표 예시 | 라운드 활성 | 배치 메모 |
|---|---:|---|---|
| 북 | X=0, Y=1900 | 1R, 2R, 3R, 4R | 상단 중앙 게이트 |
| 남 | X=0, Y=-1900 | 1R, 2R, 3R, 4R | 하단 중앙 게이트 |
| 동 | X=1900, Y=0 | 2R, 3R, 4R | 우측 중앙 게이트 |
| 서 | X=-1900, Y=0 | 2R, 3R, 4R | 좌측 중앙 게이트 |
| 북동 | X=1350, Y=1350 | 3R, 4R | 우상단 대각선 게이트 |
| 남서 | X=-1350, Y=-1350 | 3R, 4R | 좌하단 대각선 게이트 |
| 북서 | X=-1350, Y=1350 | 4R | 좌상단 대각선 게이트 |
| 남동 | X=1350, Y=-1350 | 4R | 우하단 대각선 게이트 |
| 중앙 보스 | X=0, Y=0 | 5R | 중앙 보스 출현 |

## 8. 엄폐/동선 배치

- 중앙 링 주변에는 낮은 엄폐물을 8개 정도 배치해 플레이어가 시계/반시계 방향으로 이동하며 짧게 끊어 싸울 수 있게 한다.
- 북/남/동/서 축에는 높은 엄폐물을 두어 직선 접근을 완전히 비우지 않는다.
- 외곽 대각선 입구 주변에는 엄폐 구역을 배치하되, 중앙보다 안전해 보이지 않게 한다.
- 파란 이동 경로는 중앙 링 순환을 유도하고, 빨간 적 접근 경로는 각 게이트에서 중앙으로 모이게 한다.
- 보급 상자와 회복 아이템은 중앙에서 한 번 움직여야 닿는 거리로 두어, 중앙 유지와 자원 회수 사이에 선택을 만들도록 한다.

## 9. 맵 의도

- 중앙 유지가 핵심인 방어형 전투다.
- 라운드가 진행될수록 접근 방향이 늘어나며, 플레이어 시야 확인 부담이 커진다.
- 중앙 링은 플레이어의 추천 이동 경로이고, 외곽 체류는 포위 위험을 높인다.
- 엄폐물과 보급은 생존을 돕지만 한 위치에 오래 머물 수 없게 분산한다.
- 5라운드 보스는 중앙 출현으로 기존 방어 흐름을 뒤집는다.
