# 02. Map And Wave Metrics

## 1. 맵 기본 수치

Unreal Engine 기준 1 Unreal Unit = 1 cm로 가정한다.

| 항목 | 값 |
|---|---:|
| 전체 맵 크기 | 4000 x 4000 uu |
| 실제 감각 크기 | 40m x 40m |
| 중앙 전투 구역 반경 | 800 uu |
| 중앙 안전/시작 구역 반경 | 300 uu |
| 중앙 순환 이동 링 반경 | 700~1100 uu |
| 외곽 스폰 거리 | 중심 기준 1800~2000 uu |
| 엄폐물 높이 | 120~180 uu |
| 플레이어 키 기준 | 약 180 uu |
| 주요 통로 폭 | 450~700 uu |
| 대각선 진입 통로 폭 | 400~600 uu |

## 2. 좌표계 기준

| 방향 | 좌표 예시 | 라운드 활성 |
|---|---:|---|
| 북 | X=0, Y=1900 | 1R, 2R, 3R, 4R |
| 남 | X=0, Y=-1900 | 1R, 2R, 3R, 4R |
| 동 | X=1900, Y=0 | 2R, 3R, 4R |
| 서 | X=-1900, Y=0 | 2R, 3R, 4R |
| 북동 | X=1350, Y=1350 | 3R, 4R |
| 남서 | X=-1350, Y=-1350 | 3R, 4R |
| 북서 | X=-1350, Y=1350 | 4R |
| 남동 | X=1350, Y=-1350 | 4R |
| 중앙 보스 | X=0, Y=0 | 5R |

## 7. 맵 의도

- 중앙을 계속 지키는 것이 핵심이다.
- 라운드가 진행될수록 플레이어가 확인해야 하는 방향이 늘어난다.
- 엄폐물은 중앙에서 너무 멀지 않게 배치한다.
- 외곽에 머무르면 포위되도록 설계한다.
- 5라운드 보스는 중앙 출현으로 기존 방어 흐름을 뒤집는다.
